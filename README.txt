wildtag.ai - Camera Trap Image Processing
==========================================
Beta 1 - June 2026

DOWNLOAD
  wildtag.ai (zip):  https://drive.google.com/uc?export=download&confirm=1&id=1KUhXmjFb6TVQNpbVqN4Rqbhe_c6ytiML
  User manual (PDF): https://drive.google.com/uc?export=download&confirm=1&id=1S22SNhwy7V_HexvGVYlxwSCmrYk2mdVJ

REQUIREMENTS
  - Windows 10 or 11 (64-bit)
  - No internet connection required after setup
  - No installation needed

GETTING STARTED

  1. Download and unzip
     Right-click the downloaded zip and select "Extract All".
     Choose a permanent location with around 5 GB of free space.
     Do not run wildtag from inside the zip file.

  2. Move the folder somewhere permanent
     For example: C:\Users\YourName\wildtag.ai
     Avoid paths with special characters or very long names.

  3. Launch wildtag
     Open the folder and double-click wildtag.bat
     A brief console window appears, then the app opens.

  4. Run your first job
     - Click Browse to select your image folder
     - Choose a detector and species classifier
     - Click Run wildtag

MODELS INCLUDED
  - MegaDetector v5a     (animal detection)
  - DeepFaune v1.4       (European species classification)
  - SpeciesNet Global    (Google, global species classification)

TROUBLESHOOTING
  - If the app does not open, check that the folder path contains
    no spaces or unusual characters.
  - If you see a Windows security warning, click "More info" then
    "Run anyway". This is normal for software not yet code-signed.
  - Do not move or rename the wildtag_env folder. The app depends
    on it being in the same location as wildtag.bat.

wildtag.ai - Volunteer Instructions

Thank you for helping validate camera trap images. This walks you through everything, step by step. It takes a few minutes to get started and needs no technical experience. You install the small wildtag Validate app once, then reuse it for every set of images you are sent.

Species validation  ·  css6@st-andrews.ac.uk

First time only - get the app

The project lead will send you the wildtag Validate app once: a single file called wildtag_validate.exe. Save it somewhere permanent, such as your Desktop. You only need it once - every image package you are sent afterwards uses the same app. There is nothing to install, and no need for Python or internet access.

Windows may show a blue "Windows protected your PC" warning the first time you open it, because the app is not digitally signed. Click "More info", then "Run anyway". This is expected and safe - it happens because the app is new, not because anything is wrong.

What's in an image package

When you unzip a package you were sent, you will see a validation folder containing a sub-folder named after the species you are validating, with the images inside it and a small spreadsheet. That is all - the app is separate (see above).

Step 1 - Unzip the package

1
Right-click the zip file you were sent.
2
Choose "Extract All..." and pick a permanent location, for example your Desktop.
3
Note where you extracted it - you will point the app at this folder next.

Step 2 - Open the app

1
Double-click wildtag_validate.exe (the app the project lead sent you).
2
The wildtag window opens straight to the validation view.

Step 3 - Validate the images

1
Click the Validate tab on the left (it is usually already selected).
2
Click Open folder and select the folder you unzipped. wildtag finds the images inside automatically.
3
A gallery of images appears, each already labelled with the species wildtag detected, with a confidence score below it.
4
For each image: if the label looks correct, do nothing and move on. If it looks wrong, click the image and choose the correct species from the list, then apply the correction.
5
If the correct species is not in the list, use the "Not listed? Add a label" box to add it. Your new label is then available for the rest of your images.
6
If you genuinely cannot identify the animal, choose "unidentifiable" from the top of the list rather than guessing.
7
When you have been through a batch, click Mark batch complete and confirm. Repeat until every batch is done, then close wildtag.
To correct several images that share the same error at once, hold Ctrl and click each one (selected tiles turn blue), then click any selected tile to correct them all together.
Any other detections in the same photo are shown as a thinner amber box. You do not need to do anything with those - they are just there for context.

Step 4 - Send your results back

Either of these works, whichever is easier for you:

A
Send the whole folder Right-click the folder you unzipped, choose "Send to" then "Compressed (zipped) folder", and send the resulting zip to the project lead.
B
Send just your results file Open validation\ and then the species sub-folder inside the folder you unzipped, and return the single file whose name ends in _validation.csv (for example fox_001_validation.csv). This is much smaller to send. You may rename it if you like - the name does not matter.
Please do not open the ..._validation.csv file in Excel or any other program before returning it, as that can quietly corrupt it.

A few important notes

  • You only need to flag images where the label is wrong. Correct ones need no action.
  • If you genuinely cannot identify what is in an image, choose "unidentifiable" rather than guessing.
  • Please do not rename, move, or delete any image files.
  • Images containing people are automatically blurred for privacy.
  • Take your time - accuracy matters more than speed.

Thank you again for your help with this project.

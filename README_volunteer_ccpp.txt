wildtag.ai - Species Validation
================================
Thank you for helping validate these camera trap images.

GETTING STARTED

  1. Unzip this file to a folder on your computer.
     Choose a permanent location and do not run it from inside the zip.

  2. Open the unzipped folder and double-click "Run wildtag.bat"
     The app will open automatically. (A small window may appear
     briefly while it starts, this is normal.)

  3. Click Browse next to "Validation folder" and select
     the unzipped folder. wildtag will find the images
     inside automatically.

  4. The gallery will show images labelled by the AI.
     For each image:
     - If the label is WRONG, click the image and a dropdown
       will appear - select correct species and click Apply
     - If you cannot identify the animal, choose
       "unidentifiable" from the top of the dropdown
     - If the correct species is not in the dropdown, use the
       "Not listed? Add a label" box to add it, it will then be
       available for the rest of your images (for now we treat 
       mustelid as marten, so we are correcting all not marten)

  5. When you have reviewed all images in a batch, click "Mark 
     batch complete".

  6. Delete the old Zip and then Zip the whole up this folder
     keeping the same name.

TIPS
  - Take your time - accuracy matters more than speed
  - If in doubt, choose "unidentifiable"
  - The confidence score shown below each image is the
    AI's certainty - low scores may need closer attention
  - Images with people are blurred for privacy

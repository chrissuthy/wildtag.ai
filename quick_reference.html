The workflow, start to finish

1 Install

Unzip the installer, run wildtag_Setup.exe, launch from the shortcut. No admin rights needed. On a security warning: More info → Run anyway.

2 Download a model

Open the Models tab and click Download on a model while online (DeepFaune recommended). One time only; runs offline afterwards.

3 Run

Run tab: Browse to your image folder, pick the model, click Run wildtag.

4 Validate

Validate tab: review predictions species by species, correct errors, Mark batch complete.

5 Distribute & collect

Distribute tab: Prepare zip packages for volunteers; drop returned zips in collect\ and Merge.

6 Export & review

Distribute: Export Camtrap DP and favourites. Summary: stats, species counts, map.

Tabs at a glance

Models
  • Download / Remove a model per card
  • Status: Not installed / Installed / Planned
  • Needs internet once; offline after
Run wildtag
  • Browse image folder
  • Pick Species identification model
  • Run wildtag / Stop (resumes if interrupted)
Validate
  • Click an image to flag / correct it
  • Ctrl+click = select several, correct together
  • Mark batch complete when done
  • Repair folders fixes "image not found"
Distribute
  • Prepare zip packages (never sends an image twice)
  • Merge returned zips from collect\
  • Export Camtrap DP / favourites
Summary
  • What was processed; validation progress
  • Detections per species; confusion matrix
  • File locations; Launch map
Models to choose
  • DeepFaune v1.4 - UK/Europe, fast, offline (~1.1 GB)
  • SpeciesNet - global (2000+ species); use a geo-filter to keep it fast

Handy to know

Validation shortcuts

  • Ctrl+click tiles to multi-select, then correct all at once
  • Press E to change contrast on an open image
  • Heart a tile to mark it a favourite for later export
  • Humans are auto-pixelated; originals never changed

Deployment metadata

For the map and Camtrap DP export, add a deployment.csv (one row per site: name, lat, long, start and retrieval dates). Use Save deployment.csv template to start one.

Troubleshooting

Run tab dropdown empty? No model is downloaded yet - open Models and download one while online.
Tiles show "Image not found"? The folder self-repairs on open; or click Repair folders. Nothing is lost.
SpeciesNet slow? Set a Geographic filter (your country) in the Run options - it narrows the global model to your region and speeds it up a lot. A GPU helps for very large projects.
Run interrupted? Reopen the project - wildtag offers to finish where it left off.

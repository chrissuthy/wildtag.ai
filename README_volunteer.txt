wildtag.ai - Species Validation
================================
Thank you for helping validate these camera trap images.

WHAT YOU NEED (ONE TIME)

  The project lead will send you the wildtag Validate app once: a single
  file called wildtag_validate.exe. Save it somewhere permanent (for example
  your Desktop). You only need it once, every image package you receive
  afterwards uses the same app.

  (No installation, no Python needed. If Windows SmartScreen warns about an
  unrecognised app the first time, choose "More info" then "Run anyway".)

GETTING STARTED

  1. Unzip the image package you were sent to a folder on your computer.
     Choose a permanent location and do not work from inside the zip.

  2. Open the wildtag Validate app (wildtag_validate.exe).

  3. Click the Validate tab, then click "Open folder" and select the
     folder you just unzipped. wildtag will find the images inside
     automatically.

  4. The gallery will show images labelled by the AI. For each image:
     - If the label looks CORRECT, leave it.
     - If the label is WRONG, click the image and choose the right species.
     - If you cannot identify the animal, choose "unidentifiable".
     - If the correct species is not listed, use the "Not listed? Add a
       label" box to add it; it is then available for the rest of your images.

  5. When you have reviewed all images in a batch, click
     "Mark batch complete".

  6. Send your results back. Two easy ways, whichever you prefer:
       - Simplest: right-click the unzipped folder, choose
         "Send to" > "Compressed (zipped) folder", and return the zip.
       - Smaller: open the species subfolder inside validation\ and return
         just the file ending in "_validation.csv" (for example
         fox_001_validation.csv). You can rename it if you like; the name
         does not matter.
     Please do not open that .csv in Excel before returning it.

TIPS
  - Take your time - accuracy matters more than speed.
  - If in doubt, choose "unidentifiable".
  - The confidence score shown below each image is the AI's certainty;
    low scores may need closer attention.
  - Images with people are blurred for privacy.
